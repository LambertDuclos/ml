# Detours

Prior knowledge the course assumed and nobody taught, backfilled when a lesson got stuck on it
(`CLAUDE.md`, "Gaps"). One folder per detour, `courses/detours/<topic>/`, the same shape as a
lesson: `README.md`, a `test_*.py` that covers what the lesson needed and nothing more, my file,
`notes.md`. One or two sittings; the lesson waits. Maths gaps go to `courses/maths/` instead, by
pulling the matching block forward, unless they sit below its first block.
